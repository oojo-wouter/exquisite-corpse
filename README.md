# Exquisite corpse

A proof of concept of the cadavre exquis game. Each player draws or writes one part without seeing the rest, folds it, and passes it on with a link. The whole figure or sentence is revealed at the end.

- **Drawing edition:** start from dots. The next player only sees the dots where your lines cross the fold.
- **Words edition:** the next player only sees your last word.
- **Play on one phone** (pass it around) or **over a link** (each player on their own phone).
- The whole game travels inside the share link, so there is no server or account.

Everything is in `index.html`. It is published with GitHub Pages.
